# C · 红色记忆

## 主题范围
湘南起义及相关革命史、地方党史、抗战、革命遗址、红色人物。

## 层级
- **湘南起义**（最厚实的专题之一）
  - 史料汇编与专题研究（历史背景、军地党组织、湘南特委）
  - 分县专题（起义在宜章／郴县／耒阳／安仁／临武等）
  - 关联事件：年关暴动、贝溪起义等地方武装斗争
- **地方党史**：市县党史大事记、执政纪事、组织史资料
- **抗战**：县域抗战纪实、抗战陈列展、老兵影像
- **革命遗址**：遗址普查登记材料（旧址、故居，含形成/利用年代、现状评估）
- **红色人物**：邓中夏（工运领袖，学术研讨文献密集）、唐天际等郴籍将帅；英模报告文学
- **当代延伸**：剿匪史料、纪念专辑、知青岁月

## 关联
- C↔A：史实需按"年代×县域"定锚核对
- C↔D：将帅与人物生平互见（人物群有更完整名录）
- C↔I：革命遗址今天多为纪念地与景区（保护利用走向）
- C↔E：口头回忆、歌谣等民间记述是补充材料源
